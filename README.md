# Ezra DCP Bucket List

A personal Disney College Program completionist tracker for Ezra.

## Included
- Responsive desktop/mobile layout based on the James DCP tracker
- Orange + blue Ezra theme
- 16 core bucket-list quests
- Main, Side, Rare and Legendary tiers
- Hidden secret achievements that reveal automatically
- Random quest picker
- Local progress saving
- Export/import progress backups
- PWA / Add to Home Screen support
- Offline app-shell caching

## Hosting
Designed for GitHub Pages from the `main` branch and repository root.

Personal/unofficial project. Not affiliated with Disney or Universal.
